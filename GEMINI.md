# Gemini Project Context

Before making UI, HTML, CSS, component, template, or design-system changes, read `DESIGN.md`.

`DESIGN.md` follows the Google DESIGN.md alpha structure: YAML front matter for exact tokens, followed by Markdown design rationale and generation guardrails.

Use the existing CAAT tokens and component classes. Do not introduce new colors, typefaces, shadows, border radii, page-section patterns, or one-off component styles when a documented CAAT pattern exists.
