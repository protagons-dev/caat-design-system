Component Contract

Side Navigation

Left-hand section navigation for Level 3 and Level 4 pages. Shows the L2 section title, its L3 children, and — under the active L3 item only — that item's L4 children. The mega nav stops at L3 (see the Navigation Model); this component is where L4 lives on desktop.

Why CAAT

An L3 page with no children: the current link is highlighted, no sublist renders.

1. Summary

The Side Navigation orients users inside one L2 section. It is required on every L3 and L4 page and never appears on L1/L2 pages (those are served by the mega nav and section landing layouts). It renders at most two visible depths at once: all L3 siblings, plus the L4 children of the active L3 item only — never the full L4 tree.

StatusReady
TypeNavigation / wayfinding
JSNone — server-rendered, links only
Used withBreadcrumb (required on the same pages), Navigation (mega nav supplies L1–L3 entry points)

3. Authoring Fields

Not authored per page — the component derives its content from the content tree (current page's L2 ancestor and its descendants). The only authorable options:

FieldTypeRequiredDefaultNotes
StickyCheckboxNoOnSticky below the header on desktop (--sticky)
Hide pagesPathfield multiNo—Exclude specific child pages (mirrors "Hide in navigation")

4. Validation Rules

RuleBehaviour
L3/L4 pages onlyThe component does not render on L1/L2 pages (template policy)
Two visible depths maxOnly the active L3 item renders its L4 sublist; sibling L3 sublists stay closed
No L5The IA stops at L4; deeper pages are a content-architecture error and are not rendered
Current markingExactly one aria-current="page"; ancestors of the current page get aria-current="true"

5. Content Guidance

  • Labels are page titles (or their short navigation titles) — never rewritten copy.
  • Keep L3 lists scannable: 4–8 items; if a section needs more, the IA needs restructuring, not a longer nav.
  • The section title links to the L2 landing page — it is a link, not a heading.

6. Semantic HTML

<nav class="caat-side-nav caat-side-nav--sticky" aria-label="Section navigation">
  <a class="caat-side-nav__title" href="/pension-solutions/">Pension solutions</a>   <!-- L2 -->
  <ul class="caat-side-nav__list">
    <li><a class="caat-side-nav__link" href="…">Why CAAT</a></li>                    <!-- L3 -->
    <li>
      <a class="caat-side-nav__link" href="…" aria-current="true">DBplus</a>          <!-- L3 ancestor -->
      <ul class="caat-side-nav__sublist">                                             <!-- L4: active L3 only -->
        <li><a class="caat-side-nav__link" href="…">How DBplus works</a></li>
        <li><a class="caat-side-nav__link" href="…" aria-current="page">Contribution rates</a></li>
      </ul>
    </li>
  </ul>
</nav>

Place inside the page grid: col-lg-3 for the nav, col-lg-9 for content. Below 992 px the grid stacks the nav above the content (Responsive foundation).

9. SEO

Server-rendered crawlable links reinforcing section structure — a primary internal-linking surface for L4 pages, which the mega nav deliberately omits.

11. AEM Implementation Notes

  • Resource type: caat/components/side-nav; include in the L3/L4 page templates' left column — not authorable into other parsys positions.
  • Tree is computed from the current page path: ascend to the L2 ancestor, list its children (L3) honouring Hide in navigation, expand only the L3 ancestor of the current page.
  • Navigation titles (jcr:title / nav title override) supply labels.

12. Dialog Model

Minimal — content is tree-derived, not authored.

{

13. QA Acceptance Checklist

  • Renders on every L3/L4 page; absent on L1/L2 pages.
  • Exactly one aria-current="page"; L3 ancestor carries aria-current="true".
  • Only the active L3 item shows its L4 sublist.
  • Stacks above content below 992 px; sticky on desktop when enabled.
  • Focus ring visible on every link; hover/current styles match Interaction States.
  • Labels match page navigation titles; hidden pages excluded.

14. Definition of Done

  • Tree derivation verified against the content architecture (L2 root, L3 list, active-branch L4).
  • Breadcrumb + side nav present together on L3/L4 templates; mega nav unchanged.
  • QA checklist passes on an L3 page, an L4 page, and a hidden-page case.
